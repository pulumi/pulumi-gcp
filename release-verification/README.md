# release-verification

Minimal programs, one per language, that the release verification workflow
(`.github/workflows/verify-release.yml`) runs against the published provider
and SDKs on Linux, macOS and Windows after a release. The workflow uses the
`pulumi/verify-provider-release` action and is generated by `make ci-mgmt` from
the `releaseVerification` block in `.ci-mgmt.yaml`.

| Language | Directory |
| -------- | --------- |
| Node.js  | `nodejs`  |
| Python   | `python`  |
| .NET     | `dotnet`  |
| Go       | `go`      |

Do not delete or rename these directories without updating
`releaseVerification` in `.ci-mgmt.yaml` and re-running `make ci-mgmt` in the
same change.

The example tests in `examples/` may also use these programs, but they are not
what release verification depends on: removing a test must not remove its
directory.
